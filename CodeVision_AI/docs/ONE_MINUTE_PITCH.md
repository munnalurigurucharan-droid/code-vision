# One-minute project pitch

**0–10 seconds — problem**

“When we join a new repository, we don't know where to start. Worse, teams repeat bug investigations because old debugging decisions are forgotten.”

**10–25 seconds — solution**

“CodeVision imports a GitHub project or ZIP, scans Python code with AST, identifies functions and imports, and draws a Mermaid dependency map. It does this without executing untrusted source.”

**25–45 seconds — why Hindsight**

“The critical difference is memory. We record a bug, its cause, a fix, and what failed. Hindsight Retain saves it; Recall brings that historical evidence back when the same symptom appears; Reflect summarizes earlier lessons.”

**45–60 seconds — demo + value**

“Our synthetic authentication example uses `startswith()` and incorrectly accepts a suffixed token. We show the same question before and after Hindsight memory, then verify the recalled fix against code. It is designed for faster onboarding and less repeated debugging work.”

## Simple 10-second answer

“CodeVision is a repository explorer and debugging assistant with a real Hindsight memory layer. It doesn't just map today's code; it recalls what your team learned yesterday.”
